# 🌾 ฟาร์มสุขใจ - Happy Farm 2D (Stardew Valley Style)

เกมปลูกผัก ทำฟาร์ม เลี้ยงสัตว์ บริหารร้านค้า และผจญภัยสู้มอนสเตอร์ 2D สไตล์เรโทรพิกเซลอาร์ต 16-bit Cozy Retro

![Game Preview](index.html)

---

## 🌟 ฟีเจอร์เด่นในเกม (Key Features)

1. **การทำฟาร์มและปลูกพืช (Farming & Crops)**
   - ระบบแปลงดิน ร่องดิน พรวนดินด้วยจอบ รดน้ำ และหว่านเมล็ดพืช
   - พืชหลากหลายชนิด: ข้าวสาลี, แครอท, มะเขือเทศ, ข้าวโพด, สตรอเบอร์รี่, ฟักทอง ฯลฯ
   - เอฟเฟกต์สะเก็ดดิน ละอองน้ำ และแสงประกายสีทองเมื่อเก็บเกี่ยวผลผลิต

2. **คอกสัตว์เลี้ยง & เก็บผลผลิต (Animals & Petting)**
   - เลี้ยงวัวนม (นมสด), ไก่ไข่ (ไข่ไก่), แกะ (ขนแกะ) และหมู (ขุดหาเห็ดทรัฟเฟิลดำล้ำค่า)
   - ระบบลูบขนสัตว์ `[E]` เพิ่มความสุข แสดงบอลลูนหัวใจ `❤️` และเก็บเกี่ยวผลผลิต

3. **ร้านค้าเกษตรชุมชน & ลูกค้า NPC (Shop & Shopkeeper Simulation)**
   - จัดวางผลผลิตและสินค้าบนชั้นวางหน้าร้าน 4 จุด พร้อมป้ายราคาและจำนวนสินค้า
   - ลูกค้า NPC (คุณลุงทอง, คุณป้าแก้ว, น้องมะลิ, เชฟมิกซ์) เดินเข้ามาเลือกดูสินค้า มีบอลลูนความคิด และเดินไปจ่ายเงินที่เคาน์เตอร์
   - เสียงแคชเชียร์ *Ka-ching! 💰* พร้อมสะเก็ดเหรียญทองกระจายและเพิ่มค่า XP

4. **บ้านพักชาวสวน & อัปเกรดตกแต่ง (Farmhouse & Decor Buffs)**
   - เข้าพักผ่อนในบ้าน เตียงนอนฟื้นฟูพลังงาน
   - ตกแต่งบ้าน: เตาผิงหิน (ประหยัดพลังงาน), ตู้เย็น (เพิ่มบัฟอาหาร), โต๊ะน้ำชาไม้สัก, พรมเปอร์เซีย (เพิ่มความเร็วเดิน & บัฟ XP)
   - ตู้เสื้อผ้าเปลี่ยนชุดตัวละคร: หมวก, เสื้อ, กางเกงเอี๊ยม, ทรงผม

5. **ระบบป้องกันฟาร์ม & จ้างคนดูแล (Farm Defense & Automation)**
   - แมลงปีศาจบุกทำลายแปลงผักและสัตว์เลี้ยง (ด้วงทมิฬ, ต่อพิษ, หนอนกรด)
   - อาวุธยิงสกัด: หนังสติ๊ก, ปืนไรเฟิลโบราณ, ดาบเหล็กกล้า, ดาบศักดิ์สิทธิ์เอ็กซ์คาลิเบอร์
   - จ้างนายพรานคอยยิงสกัดแมลงปีศาจอัตโนมัติ
   - จ้างคนสวนช่วยรดน้ำและเก็บเกี่ยวผลผลิต

6. **โลกผจญภัย Open World & ดันเจี้ยนป่าเอลเดอร์วู้ด**
   - เดินออกจากประตูรั้วฟาร์มสู่ผืนป่าโบราณ
   - สู้มอนสเตอร์ ล่าไอเทม ขุดแร่รูบี้ เก็บสมุนไพรดวงดาว เปิดหีบสมบัติ
   - บอสสุดโหด "จอมอสูรแคธูรอส" (Kathuros) พร้อมคลื่นเพลิงทำลายล้าง

7. **ระบบเวลา สภาพอากาศ และแสงเงา (Day/Night & Atmosphere)**
   - หมุนเวียนเวลากลางวัน-กลางคืน พร้อมวงแสงตะเกียงอบอุ่นรอบตัวผู้เล่น
   - เสียงบรรยากาศธรรมชาติ: นกร้องยามเช้า และจิ้งหรีดกริ่งยามค่ำคืน

## 🎮 การควบคุม (Controls)

| ปุ่ม | คำสั่ง |
| :--- | :--- |
| **W, A, S, D** / **ลูกศร** | เดินควบคุมตัวละคร (มีระบบช่วยสไลด์หลบมุมกำแพง) |
| **คลิกซ้าย** / **Spacebar** | ใช้เครื่องมือ / พรวนดิน / รดน้ำ / เก็บเกี่ยว / ยิงอาวุธ |
| **E** | โต้ตอบ (ลูบสัตว์, เปิดประตูบ้าน/ร้านค้า, เปิดหีบสมบัติ) |
| **1 - 9, 0** | เลือกช่องไอเทมบนแถบลัด (Hotbar) |
| **Q** | เปิดหน้าต่างสมุดเควสต์และภารกิจ |
| **H** | จัดการจ้างคนดูแลฟาร์ม & นายพราน |
| **Esc** | ปิดหน้าต่างเมนูทั้งหมด |

## 🛠️ สถาปัตยกรรมและการพัฒนา (Architecture & Tech Stack)

โปรเจคได้รับการอัปเกรดเป็น **TypeScript + Vite** เพื่อรองรับการขยายตัวในระยะยาวอย่างเป็นระบบ (Modular Architecture):

- `src/types/` — Type Definitions (Items, Entities, Game State, Save Data)
- `src/data/` — Game Data & Balances (`gamedata.ts`)
- `src/audio/` — 16-bit Web Audio Synthesizer Engine (`soundEngine.ts`)
- `src/sprites/` — Procedural Canvas Pixel Art Engine (`sprites.ts`)
- `src/auth/` — Multi-User Profiles & Google Cloud Save (`authManager.ts`)
- `src/engine/` — Main Game Loop & Game Mechanics (`game.ts`)
- `src/main.ts` — Vite Entry Point

## 🚀 คำสั่งการรันและพัฒนา (Development Commands)

```bash
# 1. ติดตั้ง Dependencies (ครั้งแรก)
npm install

# 2. รันโหมด Development (มี Hot Module Replacement แก้โค้ดแล้วจอเกมอัปเดตทันที)
npm run dev

# 3. ตรวจสอบ Type และ Build ไฟล์สำหรับ Production
npm run build

# 4. ทดสอบพรีวิวผลงานหลัง Build
npm run preview
```

> **📌 เล่นแบบ Standalone ออฟไลน์ทันที:**
> สำหรับการเปิดเล่นตรงๆ โดยไม่ผ่าน Dev Server สามารถดับเบิลคลิกเปิดไฟล์ `legacy/index.html` ด้วยเบราว์เซอร์ใดก็ได้ตามปกติ
